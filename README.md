# RHEMA - Portfólio Audiovisual

Projeto de portfólio profissional para a RHEMA, focado em apresentações de impacto para filmmaking, fotografia e edição.

## 🚀 Tecnologias Utilizadas

Este projeto foi construído com as seguintes tecnologias:

- **Vite**: Build tool rápida para desenvolvimento web.
- **React 18**: Biblioteca para construção de interfaces de usuário.
- **TypeScript**: Superset de JavaScript que adiciona tipagem estática.
- **Tailwind CSS**: Framework CSS utilitário para estilização.
- **shadcn/ui**: Componentes de UI reutilizáveis e acessíveis (baseados em Radix UI).
- **Lucide Icons**: Conjunto de ícones consistentes.
- **Framer Motion**: Biblioteca para animações fluidas.

## 🛠️ Funcionalidades Principais

- **Portfólio Filtrável**: Visualização de projetos por categorias (Filmmaking, Fotografia, Edição).
- **Design Responsivo**: Experiência otimizada para dispositivos móveis e desktop.
- **Navegação Intuitiva**: Uso de breadcrumbs e rotas claras para facilitar o acesso aos serviços.
- **Interface Moderna**: Uso de gradientes, sombras e tipografia (Bebas Neue) para um visual cinematográfico.

## 📦 Como Executar o Projeto

Siga os passos abaixo para rodar o projeto localmente:

1. **Clone o repositório**
   ```bash
   git clone <URL_DO_REPOSITORIO>
   ```

2. **Acesse o diretório do projeto**
   ```bash
   cd RHEMA
   ```

3. **Instale as dependências**
   ```bash
   npm install
   ```

4. **Inicie o servidor de desenvolvimento**
   ```bash
   npm run dev
   ```

5. **Acesse no navegador**
   Abra o endereço indicado no terminal (geralmente `http://localhost:5173`).

## 🏗️ Estrutura de Pastas

- `src/Componentes`: Componentes reutilizáveis (Footer, Hero, UI, etc).
- `src/pagina`: Páginas principais da aplicação (Home, Portfolio, Serviços).
- `src/ativos`: Imagens e recursos estáticos.
- `docs`: Documentação do projeto (incluindo o PRD).
